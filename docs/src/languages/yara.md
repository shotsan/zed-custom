# Yara

`Yara` language support in zed-custom is provided by the [Yara language extension](https://github.com/egibs/yara.zed-custom). Please report issues to [https://github.com/egibs/yara.zed-custom/issues](https://github.com/egibs/yara.zed-custom/issues).

- Tree-sitter: [egibs/tree-sitter-yara](https://github.com/egibs/tree-sitter-yara)
- Language Server: [avast/yls](https://github.com/avast/yls)
